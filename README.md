# Hub de Sistemas para Android

As versões do aplicativo, as notas e o SHA-256 de cada APK ficam em [Releases](https://github.com/Wisterly/hub-de-sistemas-app/releases/latest). Selecione o arquivo `.apk` na seção **Assets**. Abra o arquivo no Android e confirme a instalação.

No aplicativo, você pode verificar novas versões ao abri-lo, ao voltar para ele ou ao puxar a tela para baixo. Também pode usar **Notificações → Verificar atualizações**. Quando o download concluir, o Android abre a tela do sistema para você confirmar a atualização.
