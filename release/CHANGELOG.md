# Hub de Sistemas 0.1.0

- Carrossel 3D com os três sistemas iniciais, pesquisa, navegação por teclado, gestos e controles de seleção.
- Preferências locais, instalação PWA e acesso ao catálogo offline após a primeira visita.
- Projeto Android compartilhado com o frontend web. O app busca atualizações na abertura, ao voltar para ele ou ao puxar a tela para baixo. O canal estável usa APK assinado, manifesto de release e confirmação pelo instalador Android.
