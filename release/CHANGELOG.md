# Hub Seduc.Lab 0.1.23

- Adiciona interface dedicada no painel de "Perfil e preferências" ("Baixar aplicativo Android") para listar e baixar diretamente no próprio Hub os aplicativos Android oficiais de todos os projetos (Hub Seduc.Lab, Controle de Obras, OrçaBase.lab, OrçaCraft.lab e MediSEI.lab).
- Implementa download direto instantâneo sem abrir novas abas ou redirecionar para páginas externas.
- Habilita auto-atualização silenciosa e transparente da versão web do Hub ao entrar (`registerType: 'autoUpdate'`), sem exigir cliques manuais em avisos de atualização.
- Redireciona o painel de notificações para alertar exclusivamente sobre novas versões e atualizações dos aplicativos Android dos projetos, com botão direto de download do APK para cada projeto.
